# Repuestos Moto

Sitio web para una tienda de repuestos de moto. Tiene inicio, catálogo de productos, reseñas de clientes y un formulario de contacto.

## Tecnologías

HTML, CSS y JavaScript vanilla. Los íconos son de Font Awesome.

## Secciones

- **Inicio**: presentación de la tienda.
- **Productos**: catálogo armado con Flexbox, se acomoda solo según el tamaño de pantalla.
- **Reseñas**: opiniones de clientes organizadas con Grid.
- **Contacto**: formulario que se abre como modal, responsive con media queries.

Sitio en vivo: https://brunozanetti09.github.io/Proyecto-Curso-Front---End-JS/
